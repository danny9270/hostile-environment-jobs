Admin sign in

Sign in with a GitHub key that can edit the hostile-environment-jobs repository. Without one, this page can't see or change anything.

  1. Open GitHub: new fine-grained token.
  2. Name it "Jobs admin" and pick an expiry (a year is fine).
  3. Under Repository access choose Only select repositories and pick hostile-environment-jobs.
  4. Under Permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it below.
